*Modules:* [[file:../../graphs/export][graphs/export]]

Serialise graphs for use with external tools.

- DOT and GEXF output strings or files suitable for graphviz or Gephi
- The TikZ exporter emits a TikZ block suitable for LaTeX documents
- The cytoscape target produces a standalone HTML page using cytoscape.js

* Summary
- =to-dot= — Graphviz DOT source (as string)
- =to-gexf= — GEXF XML suitable for gephi
- =to-tikz= — TikZ picture for LaTeX
- =to-svg= — SVG output via Graphviz (via a dot file rendered with =dot=, =neato=, =circo=, =fdp=, =sfdp=, =twopi=, =osage= or =patchwork=, as per =:layout=), or internal renderer for circular-arc and poly-arc layouts.
- =to-cytoscape= — a self-contained HTML page embedding the graph via cytoscape.js

* Examples

#+begin_src janet :session examples :results none
(import graphs :prefix "")
#+end_src

#+begin_src janet :session examples :results output :wrap SRC dot
(def w (make-digraph))
(add-nodes w "a" "b")
(add-edges w ["a" "b" 1])

(print (to-dot w))
#+end_src

A TikZ picture from a =:weighted-graph= which can be used for the phylogram family

#+begin_src janet :session examples :results output :wrap src latex
(def t (make-weighted-graph))
(add-nodes t "root" "a" "b")
(add-edges t ["root" "a" 2] ["root" "b" 1])

(print (to-tikz t :layout "phylogram" :root "root" :label-edges false))
#+end_src
